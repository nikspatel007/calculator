# Project Context Template

Copy this template to create a new project context file. Name it after your project (e.g., `vermas.md`, `gourmets.md`).

---

## Project Name

[One line - what is this project?]

## Problem Statement

[What problem does this solve? Who has this problem?]

## Current State

[Where is the project now? Early idea, MVP, scaling?]

## Target Users

[Who specifically are we building for?]

## Key Assumptions

[What do we believe to be true? These should be challenged.]

## Constraints

[What can't we change? Budget, team, tech, timeline?]

## Success Criteria

[How do we know we've won?]

## Open Questions

[What don't we know yet that we need to figure out?]

---

## For the Team

Each executive should read this and apply their lens:

- **Strategist:** Does the vision align with the problem? What's the long game?
- **Product:** Who exactly has this problem? What's the job-to-be-done?
- **Business:** Is there a market? What's the business model?
- **Growth:** How do users find us? What's the activation path?
- **Critic:** What assumptions are risky? What could kill this?
